Queens Puzzle Strategy: 6 Techniques to Solve Any Board

Six logical techniques that solve every Queens puzzle without guessing, from a bird's reach to group squeezes.

1. A bird's reach

A bird rules out its row, its column, its color and every cell touching it, diagonals included. Mark those cells with an X right away.

2. Last cell

If a color, row or column has only one open cell left, the bird must go there.

3. Color in one line

If all open cells of a color sit in a single row (or column), that color's bird is in that line, so every other cell of the line is out.

4. Line inside one color

If all open cells of a row (or column) belong to one color, the row's bird is that color's bird: the rest of the color is out.

5. Group squeeze

If two colors can only fit in the same two rows, those two rows belong to them, and every other color's cells in those rows are out. The same works for three colors in three rows.

6. Blocking cell

Imagine a bird on a cell. If it would leave some color, row or column with no open cell, that cell can't hold a bird.

Birbdoku's hints use exactly these techniques: when you are stuck, a hint names the technique, highlights the row, column or color it is about and explains the step.
