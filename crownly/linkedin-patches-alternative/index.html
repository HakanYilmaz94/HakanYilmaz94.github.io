LinkedIn Patches Alternative: Daily Shikaku-Style Rectangle Puzzles

Like LinkedIn's Patches? Mosaic in Crownly is a Shikaku puzzle: split the grid into rectangles, each holding one number equal to its area. A 7×7 and a 10×10 daily board plus levels.

Patches is built on a classic Japanese puzzle, Shikaku. Crownly's Mosaic is that same classic, with a daily board for everyone and levels for when one a day isn't enough.

How Mosaic plays

  • Split the whole grid into rectangles.
  • Each rectangle holds exactly one number, and that number is its area.
  • Drag from corner to corner to draw a piece; a new piece replaces any it overlaps.
  • Every board has exactly one solution.

Daily boards and levels

Every day at 07:00 UTC there is a 7×7 daily board and a harder 10×10 one, the same for everyone. Levels go from easy to expert, and hints remove a wrong piece or point to the number with the fewest options left.
